# 系统架构与API
前端：Vue3 + TypeScript + Vite。后端：FastAPI + SQLAlchemy。事务库：PostgreSQL。部署：Docker Compose。设备边缘层建议隔离在OT网段，通过网关只读采集 OPC UA / MTConnect / 厂商SDK / MQTT；ERP通过REST或文件交换适配器连接。

## 已实现API
GET /health
GET /api/v1/dashboard
GET,POST /api/v1/machines
POST /api/v1/machines/events
GET,POST /api/v1/work-orders
POST /api/v1/work-orders/{id}/operations
POST /api/v1/production/reports
GET,POST /api/v1/quality/inspections
GET,POST /api/v1/tools
POST /api/v1/tools/{id}/consume?minutes=N
GET,POST /api/v1/materials
POST /api/v1/inventory/issue
GET /api/v1/planning/suggestions
POST /api/v1/payroll/piecework-preview?operation_code=OP10&good_qty=10
GET /api/v1/alerts
POST /api/v1/erp/inbound/work-order
POST /api/v1/demo/seed

所有生产写接口在正式上线前需加JWT/OIDC、RBAC、审计、请求ID、幂等键、速率限制；ERP接口需签名校验、重试队列和对账。
